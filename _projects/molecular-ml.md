Molecular ML aimed to develop **bio-inspired machine learning technology** competitive with human learning in speed, flexibility, and robustness by studying the representational and organizational principles of biological brains.

## Core Idea

Biological brains learn from remarkably few examples, generalize flexibly, and do so with molecular machinery. Molecular ML asked: what if we implemented a human-like learning model in molecular populations using DNA?

## Two-Layer Architecture

1. **Human-like machine learning model**: based on dynamic neural assemblies that encode knowledge as weighted hypergraphs
2. **Molecular implementation**: in vitro DNA computing executes the model using DNA strands as computational units

## Validated Tasks

- Language processing (sentence parsing and generation)
- Visual pattern recognition
- Decision-making under uncertainty

## Publications

Key results published 2012–2015, demonstrating molecular pattern classification via DNA beacons and DNA-based language models.
