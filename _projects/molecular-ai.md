The Molecular AI project investigated **intelligent nanobiomolecular agents** that perceive, act, and learn to make decisions in biomolecular environments — bringing machine learning into the molecular world.

## Vision

Imagine nanorobots inside the body that can detect cancer markers and deliver drugs precisely, guided by learned decision policies. Molecular AI worked toward this future by implementing learning algorithms using DNA molecules as the computational substrate.

## Key Contributions

- Experimental implementation of **molecular evolutionary learning** of DNA hypernetworks for handwritten digit classification
- **Massively parallel distributed pattern recognition** using molecular computing
- In vitro DNA-based learning validated on real biomolecular systems

## Target Applications

- Molecular diagnostics
- Personalized drug delivery
- Intelligent gene therapy
- Nanorobot controllers
