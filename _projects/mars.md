MARS developed a **multimodal associative recommendation system** that leverages hypernetwork-based learning to integrate textual and visual data modalities for improved content suggestion.

## Technical Approach

- **Layered hypernetwork architecture** for capturing higher-order cross-modal associations between text and image features
- **Bidirectional inference** across modalities: text → image, image → text
- **Multimodal query expansion**: enhancing retrieval using cross-modal semantic associations

## Evaluation

Demonstrated on real **Korean magazine corpora**, showing improved content-based retrieval and recommendation accuracy over single-modality baselines.

## Connection to Lab Research

MARS built on the lab's core expertise in hypernetwork architectures, extending them from pure learning tasks to recommendation and retrieval — demonstrating their versatility across application domains.
