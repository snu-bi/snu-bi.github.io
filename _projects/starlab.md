The StarLab project, part of Korea's **SW StarLab program**, developed cognitive agents that continuously learn from human daily activities captured through multimodal wearable sensors.

## Sensors & Data Collection

- Smart glasses (Google Glass): first-person visual context
- Smartwatches: motion and physiological signals
- Real-world lifelogging over 46 days

## Core Systems

| System | Description |
|--------|-------------|
| **LifeMap** | Visualization of sensor-derived behavioral maps |
| **CogMap** | Episodic memory architecture for daily activities |
| **ActMap** | Prediction of future user activities |

## Results

- ~**82% accuracy** in predicting user behavior from real-world lifelogged data
- Dual-memory deep learning architecture inspired by neurocognitive Complementary Learning Systems (CLS) theory
- Publications at **IJCAI 2016** and **Neural Networks (2017)**
