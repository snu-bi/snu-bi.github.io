The MMG project developed a **game-based research platform** to study cognitive learning using multimodal data — text, speech, and images — drawn from TV drama episodes such as *Friends*.

## The Game

Human players and a machine learner engaged in **question-and-answer sessions** about scenes and dialogues after watching video clips. The game format:
- Made data collection natural and scalable
- Allowed measuring how memory recall improves over repeated game sessions
- Enabled building predictive models of human memory

## Theoretical Contributions

Two core principles for **human-level machine learning**:

1. **Continuity**: Forming lifelong memory incrementally, rather than learning from a static dataset
2. **Glocality**: Organizing locally specialized micromodules in a globally connected network

## Empirical Finding

Human recall **improves steadily** with the number of game sessions — validating the game as a tool for studying and improving long-term memory in both humans and machines.
