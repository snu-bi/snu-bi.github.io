The Embodied Intelligence project investigated AI systems with **physical embodiment** capable of perceiving and acting in the real world, spanning mobile robot perception to robotic arm manipulation.

## Research Areas

### Multimodal Perception for Mobile Robots
- Object detection and visual grounding
- Multi-agent 2D map merging for cooperative navigation
- Robust Map Fusion with visual attention (ICRA 2023)

### Language-Conditioned Robot Manipulation
- ROS-based real-world robot control system
- Natural language-conditioned lifelong learning for robotic arm manipulation
- Exit-aware object tracking for safe manipulation

## Key Papers (2023)

- **GVCCI**: Lifelong Visual Grounding via Continual Contrastive Learning for Individual Instance — *IROS 2023*
- **EXOT**: Exit-Aware Object Tracker for Safe Robotic Manipulation — *ICRA 2023*
- **Robust Map Fusion**: Visual Attention-based Map Fusion for Multi-Agent Rendezvous — *ICRA 2023*
