DietAdvisor was a **smartphone-based intelligent agent** providing personalized meal and exercise recommendations, combining mobile sensing with intelligent reasoning to support health and wellness goals.

## Features

- Personalized **meal recommendations** tailored to nutritional needs and user preferences
- **Exercise suggestions** adapted to user activity level and daily context
- Context-aware reasoning using mobile sensor data (location, time, activity)
- Agent-based architecture enabling adaptive, goal-directed advice

## Significance

DietAdvisor represents an early effort in the lab to apply intelligent agent technology to personal health on mobile platforms — a domain that has since grown enormously with health apps, wearables, and AI nutrition coaching.
