This SKT-sponsored project investigated **hypernetwork models as a computational architecture for language learning**, where weighted random hypergraph structures encode higher-order probabilistic relations through an evolutionary self-organizing process.

## The Hypernetwork Approach

A hypernetwork is a weighted random hypergraph where each hyperedge connects multiple nodes (words, concepts) with a learned weight. The network **self-organizes** through an evolutionary process inspired by molecular self-assembly, gradually encoding grammar and semantic relations.

## Key Insight

Grammar rules and linguistic memory can be **evolved** rather than hand-crafted. Evolving populations of hyperedges discover statistical patterns in language that generalize across contexts.

## Experiments

- **Sentence generation** from video drama corpora
- **Cross-modal language-vision translation** tasks
- Demonstrated that hypernetwork structures capture both local syntactic patterns and global semantic relations
