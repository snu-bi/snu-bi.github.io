The MEC project developed **evolutionary algorithms operating at the molecular level** using DNA molecules as the computational substrate — one of the lab's foundational projects in bio-inspired computing.

## Phases

### Phase I & II (2000–2006): Molecular Evolutionary Algorithms
- DNA-based solutions to combinatorial problems (**Traveling Salesman Problem**)
- Multiobjective optimization of DNA sequences for reliable computing
- Version-space machine learning with DNA molecules
- In vitro implementation of evolutionary search using molecular biology techniques

### Phase III (2006–2009): DNA Computing for Molecular Diagnosis
- DNA Computing Algorithms for **Molecular Diagnosis**
- Gene expression profile diagnosis using molecular computing
- **MicroRNA biomarker detection** with DNA-based computing systems
- Bridging molecular computing and biomedical informatics

## Significance

MEC was among the earliest sustained efforts globally to implement practical machine learning algorithms using DNA molecules, establishing the lab's unique interdisciplinary position at the boundary of computer science and molecular biology.
