SQL Server 2005 Data Mining Overview

Dr. Peter Kim

KCOMS Ltd., USA

2005. 10. 4

301-421, 11:00-12:00 AM

 
Data mining technology involves multiple disciplines from database, statistics and artificial intelligence. As competition grows in business environment, agility in decision making with right information has become an essential survival guide in every business industry. Data mining is one of the key technologies to enable the agility. Since its inception, Microsoft SQL Server data mining team has put tremendous efforts to make data mining technology appealing to a much wider audience. This talk will introduce what's coming in the new version of Microsoft SQL Server data mining component. In particular, I'll cover platform support such as algorithms, language, performance, and extensibility.
