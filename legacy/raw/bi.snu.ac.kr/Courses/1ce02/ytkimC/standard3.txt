4번 채점 기준.

밑줄 다섯개 각 5점씩 5*5 = 25
(전체 흐름은 틀려도 다섯개를 독립적으로 채점했음. 즉 개당 답만 맞으면 5점씩)

- 이유 설명 없으면 0점.
- call by value 나 값의 복사 가 있으면 20점
- "call by value" 라고만 적으면 10점
- call by reference 를 적으면 5점 감점. (pointer 는 call by value 임. call by reference 효과를 볼 수 있는 것임)
- 거의 비슷하면 15점
- 메모리 내용을 들어 설명까지 곁들이면 추가 5점
(이유 설명부분은 추가점까지 받으면 25점입니다.)

따라서, 총 25+25 = 50점 만점입니다.
