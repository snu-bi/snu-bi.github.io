Project #1: Solving Classification Problems using Neural Networks

2005년 1학기


Problem definition:
  • 문제에 대해, Feedforward NN 학습 및 적용해보기
  • epoch, hidden layer, neuron의 수에 따른 일반화 성능 비교
  • 미지의 문제에 대해 최고 성능을 찾아 보기

Data sets:
  • Pima Indians Diabetes Database:
    • 768 instances (binary class)
    • 8 attributes + one of two classes
  • Challenge:
    • 5822 instances for train set, 4000 instances for test set
    • 86 attributes (1 ~ 85 for input, 86 for target label)
    • Labels of test set are hidden.
    • Submit the labels and find the best performance!
    • http://knight.snu.ac.kr/aiproj1/ai_nn.asp
